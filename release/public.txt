# Scene Lab: the public allow-list

# Scene Lab is developed in a private working repository. Its release script (not part of this repository) copies a
# git-tracked file into this public repository only when a line below matches its path, and only after a leak check
# has passed it. Anything not matched stays private, so a new file is private until a line here names it.
#
# Format: one glob per line, relative to the repository root, with forward slashes. "*" matches inside one folder,
# "**" matches any depth. A line starting with "!" takes paths back out (it wins over every other line). Blank
# lines and lines starting with "#" are ignored. Untracked and ignored files (build/, out/, node_modules/, .env)
# are never copied, whatever matches.
