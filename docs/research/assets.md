# Research: assets (2026-11-14, v0.2 sweep)

PROVIDERS (endpoint | auth | licence field/filter | the rule that shapes code)

- Iconify: GET api.iconify.design/search?query=&limit(32-999)&prefixes=&category= returns `icons` as "prefix:name" plus `collections`. GET /collections?prefixes= returns a per-set `license{title,spdx,url}` and `author`. No key. No rate limit is published, but the docs ask callers to avoid needless searches. Rule: keep a per-set SPDX allowlist (MIT/Apache/ISC/OFL/CC0/CC-BY) and credit CC-BY sets. https://iconify.design/docs/api/search.html https://iconify.design/docs/api/collections.html
- Noun Project v2: GET /v2/icon?query=&limit_to_public_domain=1&include_svg=1&thumbnail_size=&limit=&next_page. Download: /v2/icon/{id}/download?filetype=svg&color=. OAuth 1.0a one-legged (key and secret). Usage is a monthly quota, read via /v2/client/usage. Docs: "free api access is limited to public domain icons" for downloads, so send limit_to_public_domain=1. Results carry `attribution`, `license_description` and `creator`. Asset URLs expire within an hour. https://api.thenounproject.com/documentation.html https://rdrr.io/cran/httr/src/demo/oauth1-nounproject.r
- Wikimedia Commons: api.php?action=query&generator=search&gsrnamespace=6&gsrsearch="q filetype:bitmap|drawing|video"&prop=imageinfo&iiprop=url|extmetadata&iiurlwidth=. Licence: extmetadata `LicenseShortName`, `LicenseUrl`, `Artist` (HTML), `AttributionRequired`, `Restrictions`. Rule: a descriptive User-Agent is mandatory. Multi-licence values are unreliable, so take the most permissive with care. https://www.mediawiki.org/wiki/Extension:CommonsMetadata https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy https://www.mediawiki.org/wiki/Help:CirrusSearch
- Openverse: /v1/images/ and /v1/audio/?q=&license_type=commercial,modification&license=cc0,pdm,by,by-sa&category=. Optional client_credentials token (expires 36000 s). Fields: license, license_version, license_url, attribution, url, foreign_landing_url. Rule: send license_type=modification, because a video is an adaptation (see the CC note). The anonymous limit of about 20/min and 200/day is third-party only. https://api.openverse.org/v1/schema/ https://apify.com/logiover/openverse-scraper
- NASA Image Library: GET images-api.nasa.gov/search?q=&media_type=image,video,audio&year_start=&page_size(100). /asset/{nasa_id} lists ~orig/~medium/~small/~thumb (pick one); /captions/{nasa_id} gives VTT/SRT. No key. Rule: credit NASA, no logos and no implied endorsement, and check the description for a third-party copyright holder. https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf https://www.nasa.gov/nasa-brand-center/images-and-media/
- NASA APOD: /planetary/apod?api_key=&date|start_date|count(1-25). Fields: url, hdurl, media_type, copyright. "Anything without a copyright returned field is generally NASA and in the public domain", so a non-empty `copyright` means reject or ask permission. DEMO_KEY allows 30/h and 50/day. https://github.com/nasa/apod-api https://api.data.gov/docs/developer-manual
- Smithsonian: GET api.si.edu/openaccess/api/v1.0/search?q=&start&rows&api_key. `q` takes boolean and fielded syntax. Rule: keep only media whose `usage.access=="CC0"` (field name from experience, check against a live response). https://glama.ai/mcp/servers/@molanojustin/smithsonian-mcp/blob/af3399c332cd020f4c1d7f12373e36a313efb299/dev/documentation/API_Documentation.md
- Europeana: api.europeana.eu/record/v2/search.json?wskey&query&reusability=open&media=true&rows&cursor. Fields: `rights` (licence URI), edmIsShownBy (media). The official docs returned 403 here, so this is from secondary sources. https://search.r-project.org/CRAN/refmans/europeanaR/html/query_search_api.html https://pro.europeana.eu/blog/can-i-use-it
- The Met: use /public/collection/v1.1/search?q&hasImages=true&limit(<=500). /v1/search retired on 2026-10-01. The object record carries `isPublicDomain` and primaryImage/primaryImageSmall; there is no search filter for it, so filter per object. No key. Stay under 80 req/s. https://metmuseum.github.io/
- Pixabay: /api/?image_type=photo|illustration|vector&per_page(3-200). /api/videos/?video_type=film|animation returns videos.{large,medium,small,tiny}.url. vectorURL needs full access. Pixabay Content License. Existing 24 h cache rule stands. https://pixabay.com/api/docs/
- Unsplash: /search/photos?query&per_page(<=30)&orientation&content_filter=high, header Authorization: Client-ID. Call links.download_location on every use. Unsplash+: the official docs have no `plus` or `premium` flag or exclude parameter. Third parties report `premium`/`plus` booleans and default exclusion, so drop any hit where either is true. https://unsplash.com/documentation https://apify.com/memo23/unsplash-image-scraper
- Freesound: /apiv2/search/?query&filter=license:"Creative Commons 0" duration:[0 TO 10]&fields=id,name,license,username,previews&page_size(<=150). Token auth covers previews (preview-hq-mp3/ogg). The original file needs OAuth2. Throttling is per user. API ToS: commercial use is negotiated, and keep only temporary copies. https://freesound.org/docs/api/resources_apiv2.html https://freesound.org/help/tos_api/
- Jamendo: /v3.0/tracks?client_id&search&tags&ccnd=false&include=licenses&audiodlformat=mp32&limit(<=200). Fields: license_ccurl, audiodownload (empty unless audiodownload_allowed). API terms: "freely for non-commercial uses", no caching beyond what operation needs, credit artist and Jamendo and link the track page. https://developer.jamendo.com/v3.0/tracks https://devportal.jamendo.com/api_terms_of_use
- Fontsource: api.fontsource.org/v1/fonts and /v1/fonts/{id}. variants[weight][style][subset].url has woff2/woff/ttf. No key. 2500 req/10 s. https://fontsource.org/docs/api/font-id https://fontsource.org/docs/api/introduction
- Poly Haven: api.polyhaven.com/files/{id} returns map → resolution → format{url,size,md5}, plus gltf/blend packages with an `include` list. Assets are CC0. A unique User-Agent or Referer is required. Live-API use needs a "Powered by Poly Haven" credit. https://raw.githubusercontent.com/Poly-Haven/Public-API/master/ToS.md
- Sketchfab: /v3/search?type=models&downloadable=true&license=cc0|by|by-sa (from secondary sources). /v3/models/{uid}/download needs a token and returns gltf/usdz {url,size,expires≈300}. Do not cache those URLs; download at once. CC licences need a credit (not CC0). https://sketchfab.com/developers/download-api/downloading-models https://sketchfab.com/blogs/community/refine-downloadable-model-searches-with-new-license-filters https://help.sketchfab.com/en/articles/16152031-api-overview

CC 4.0 AND VIDEO: confirmed. "Where the Licensed Material is a musical work, performance, or sound recording, Adapted Material is always produced where the Licensed Material is synched in timed relation with a moving image." ND allows producing adapted material but not sharing it, so ND audio can never go in a shared video. https://creativecommons.org/licenses/by-nd/4.0/legalcode.en

RECOMMENDED ADDITIONS
1. Art Institute of Chicago: query[term][is_public_domain]=true, then IIIF {iiif_url}/{image_id}/full/843,/0/default.jpg. No key; send an AIC-User-Agent header. Gives CC0 art. The 60/min limit is unconfirmed. https://api.artic.edu/docs
2. Cleveland Museum of Art: /api/artworks/?q&cc0&has_image=1 gives images.print up to 3400 px. `share_license_status` is the gate. No key. https://openaccess-api.clevelandart.org/
3. NIH BioArt: public-domain science illustrations ("Courtesy of NIAID"), so read each entry's licence label. It has no API, so curate a local index. https://bioart.niaid.nih.gov/faqs
4. Library of Congress: ?fo=json, no key. JSON API is limited to 20 req/min and a breach blocks for 1 h, so the rate limiter is mandatory. https://www.loc.gov/apis/json-and-yaml/working-within-limits/
5. Wellcome Collection: catalogue/v2/images, no key. Licence filter with cc-0, pdm, cc-by and others; confirm the parameter name live. Strong for medical history. https://developers.wellcomecollection.org/redocusaurus/plugin-redoc-0.yaml
6. Rijksmuseum: data.rijksmuseum.nl/search/collection, no key, imageAvailable=true. Public-domain works are CC0 and others CC BY. https://data.rijksmuseum.nl/docs/search https://www.rijksmuseum.nl/en/data/policy
7. useAnimations: MIT Lottie icons, credit optional. Vendor the files. https://github.com/useAnimations/react-useanimations
8. Bioicons, Servier and Kenney as local packs, since none has an API. Bioicons: SVG with a per-icon licence on GitHub. Servier: CC BY 4.0. Kenney: CC0. https://bioicons.com/ https://smart.servier.com/ https://kenney.nl/support

REJECT
- Lordicon free tier: requires attribution and is built on a NoDerivatives licence, so recolouring or animating is out. https://lordicon.com/licenses
- LottieFiles bulk search: no public search API is documented (the GraphQL schema is reached through their MCP server). The Lottie Simple License forbids compiling files to replicate the service. Hand-picked single files are fine. https://lottiefiles.com/page/license https://docs.lottiefiles.com/en/platform/mcp
- Openclipart: the API tutorial looks about 2021-era and availability is unverified. https://openclipart.org/api/tutorial
- ccMixter: the lic= values are mostly NC or sampling, and the result fields are undocumented. Keep it behind Jamendo at most. https://ccmixter.org/query-api
- NASA 3D Resources: "free and without copyright", but it is a git repo with no API. Clone it rather than integrate it. https://github.com/nasa/NASA-3D-Resources
- Internet Archive: licences vary per item (licenseurl) and quality is uneven. A descriptive User-Agent is required. Opt-in only. https://archive.org/developers/bots.html
- Pexels: key issuance paused (existing note).
